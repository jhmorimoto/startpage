# Mensagens de Commit

Escrever mensagens de commit em português brasileiro.

### Padrão Sugerido (Baseado em Conventional Commits)
Use o formato `<tipo>: <descrição>` para manter um histórico limpo e legível.

**Tipos comuns:**
- `feat`: Uma nova funcionalidade.
- `fix`: Correção de um erro (bug).
- `docs`: Alterações na documentação.
- `style`: Mudanças que não afetam o significado do código (espaço, formatação, ponto e vírgula, etc.).
- `refactor`: Uma alteração de código que nem corrige um bug nem adiciona uma funcionalidade.
- `perf`: Uma mudança de código que melhora o desempenho.
- `test`: Adição de testes ausentes ou correção de testes existentes.
- `chore`: Atualizações de tarefas de build, configurações de ferramentas, etc.
